# PHASE 11 — Advanced MIDI Quality UI

PHASE 11 exposes the PHASE 10 refinement controls in the web converter.

## UI controls

- Confidence Threshold: 1–127, default 20.
- Quantization Strength: 0–1, default 0.72.
- Harmonic / duplicate cleanup: on/off.
- Track / Instrument Override: JSON map by raw track index.
- Quality Report: reads the quality metadata generated by the neural pipeline.

Example override:

```json
{
  "0": {"name": "Lead Vocals", "type": "vocals"},
  "1": {"name": "Electric Bass", "type": "bass"}
}
```

Allowed types:
`vocals`, `bass`, `drums`, `piano`, `melody`, `other`.

## End-to-end flow

```text
Converter UI
   -> api/converter/create.php
   -> queue/*.json
   -> processing/worker.py
   -> neural_pipeline.py
   -> midi_quality.py
   -> final MIDI + JSON quality report
   -> api/converter/status.php
   -> api/midi/quality.php
   -> Quality Report UI
```

## Before / after statistics

The quality report contains:
- original track count
- final track count
- removed low-confidence notes
- removed duplicate notes
- merged notes
- quantized notes
- final note count
- tempo
- per-track label/type/program/channel/note count

The UI/API intentionally reports statistics produced by the actual processing engine; it does not fabricate values.

## Re-process

PHASE 11's processing API is parameterized and therefore ready for re-processing. The current converter creates a fresh conversion job with the selected settings. A dedicated one-click "Re-process existing MIDI" action can be added in PHASE 12 without changing the processing engine.

## Accuracy note

Confidence is still a proxy because the MIDI result does not carry a portable Basic Pitch confidence field. The threshold therefore filters source MIDI velocity, and the UI labels it accordingly.
